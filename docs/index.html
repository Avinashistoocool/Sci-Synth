Sci-Synth

Sci-Synth is a PDF reader extension for scientific papers. Open a PDF in its viewer, hold Alt and point at a word, sentence, equation, figure, table or scanned region. Sci-Synth sends that part of the page to the AI provider that you configure and shows the explanation next to it. The browser's own PDF viewer stays the default.

  • TypeScript
  • React
  • Vite
  • PDF.js
  • Tesseract.js (bundled OCR)
  • OpenAI · Anthropic · Gemini · Ollama
  • FastAPI (optional)
Version 1.0.0 · install from source · Chrome Web Store: coming soon

01What it does

Explain in place

Hold the trigger key and point. Sci-Synth picks a word, sentence, paragraph, equation, figure or table and asks your model about it, with nearby text as context.

Scanned pages

Bundled Tesseract runs a quick local OCR pass. With a vision model, Sci-Synth can also transcribe the scanned page you are on and the next two.

Doubts and concepts

Follow-up questions form a doubt tree per PDF, and a concept list links related answers. Notes stay in IndexedDB on your computer.

02How it works

  1. Open. You open a PDF in the Sci-Synth viewer (toolbar icon, right-click menu, file, or an allowlisted site). PDF.js renders it inside the extension.
  2. Extract. The viewer reads the text layer and its layout. Pages without text go to local OCR and, if enabled, to your vision model.
  3. Point. While you hold Alt, the viewer maps the pointer to a target. Equations, figures and tables are picked as a whole; keys 1–4 change the size.
  4. Ask. The extension sends the target text (and an image crop, if enabled) with nearby context directly to your provider. There is no proxy server.
  5. Keep. Answers are cached, and the question thread becomes part of the doubt tree for that PDF.

03The viewer is opt-in

Sci-Synth does not take over PDFs. Every PDF opens in the browser's built-in viewer until you ask for Sci-Synth.

Default: you choose each time

  • Click the toolbar icon on a PDF tab.
  • Right-click a PDF link → Open in Sci-Synth.
  • Right-click on a PDF page → Open this PDF in Sci-Synth.
  • Drop a PDF on the viewer, or use Open PDF.

Optional: per-site rule (off)

In the viewer's Document panel, select Always open PDFs from this site in Sci-Synth, or add sites in the settings. Only then does the browser ask for webRequest and access to that one site.

Tested in Chromium with the unpacked build: with no allowlist, https://arxiv.org/pdf/1706.03762 stayed in the built-in viewer; the toolbar and menu paths rendered all 15 pages in Sci-Synth with no extension console errors.

04Permissions

No <all_urls>, no tabs. Site access is optional and requested per site, when you act.

PermissionTypeWhy
storagerequiredSettings and your API key in chrome.storage.local.
unlimitedStoragerequiredCache of page text, answers and notes for large PDFs.
contextMenusrequiredThe “Open in Sci-Synth” menu items.
activeTabrequiredRead the current tab's address when you click the icon.
webRequestoptionalOnly for allowlisted sites, to detect their PDF responses.

05Privacy

  • No developer server, no analytics, no tracking.
  • PDF excerpts, questions and optional images go only to the AI provider that you configure. Use Ollama for local processing.
  • Keys stay in chrome.storage.local; cache and notes stay in IndexedDB.
  • PDF.js and Tesseract are bundled. The extension loads no remote code.

06Optional simulator (local backend)

Security model. The backend never executes code written by a model. The earlier prototype asked the LLM for Python and ran it, so a malicious PDF could inject instructions and run commands; that path is removed.

Run the backend only on your own computer (127.0.0.1). It sends PDF text to the Groq API with your key.

simulator/backend/ is an optional FastAPI service. The extension uses it only if you set a backend URL in the settings; the default is empty and the feature is hidden.

  1. Extract. The LLM reads the PDF text (wrapped as untrusted data, at most 60 000 characters) and must return a JSON equation spec: state variables, parameters, right-hand sides as math expressions, initial values, time span.
  2. Validate, without an LLM. The spec must match a strict schema. Each expression is parsed with Python’s ast and checked against an allow-list: + - * /, constant powers up to 10, numbers, declared names, t, pi, e and 15 math functions. Attributes, subscripts, strings, lambdas, other calls and unknown names are rejected with HTTP 422. The checked tree is built into numpy functions; nothing goes to eval or exec.
  3. Show. The viewer lists the exact equations and parameters before anything runs.
  4. Solve. Run simulation sends the spec to SciPy’s solve_ivp (LSODA or RK45) with a 5 s time limit, an evaluation cap and at most 5000 points, and plots the result.

A second LLM can act as an optional physics reviewer (SCISYNTH_REVIEW=1, off by default). It reads only the validated spec and returns warnings about units or signs. It is advisory: it cannot change what runs and is not a security control, because a model that checks model output can be misled by the same document. Remaining risks: a valid but physically wrong system (compare the shown equations with the paper) and CPU use up to the limits.

07Install from source

git clone https://github.com/Avinashistoocool/Sci-Synth.git
cd Sci-Synth
npm ci
npm run build
  1. Open chrome://extensions (or edge://extensions) and enable Developer mode.
  2. Select Load unpacked and select the dist folder.
  3. Open the Sci-Synth options, select a provider, enter the model and key, and select Save. Allow the access request.
  4. Select Test connection.

Optional simulator:

cd simulator/backend
pip install -r requirements.txt
python -m uvicorn main:app --host 127.0.0.1 --port 8000

08Status and limitations

  • Version 1.0.0. Not yet on the Chrome Web Store; load it unpacked.
  • You need your own AI provider key, or a local Ollama server.
  • Answer quality depends on the model. Text-only models cannot read equations or figures as images.
  • Local OCR is English-only and weak on handwriting.
  • Some PDF hosts block cross-origin reads; then Sci-Synth asks for access to that site, or you download the file.
  • The simulator handles systems of ordinary differential equations only (up to 8 state variables). The LLM can misread the paper; check the equations it shows.
