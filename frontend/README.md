# Sci-Synth frontend

This Next.js app sends a physics PDF to the Sci-Synth API.
It shows the extracted manifest and simulation data.

1. Start the API as shown in the [root guide](../README.md).
2. Run `npm ci` in this directory.
3. Run `npm run dev`.
4. Open `http://localhost:3000`.

For the API routes, controls, and limits, read [the frontend guide](docs/STE100.md).
