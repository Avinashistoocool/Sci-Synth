# Sci-Synth frontend

This Next.js app accepts a physics PDF and shows data from a simulation. The backend supplies the extraction and simulation APIs.

## Start the app

1. Start the API from the monorepo's `backend` directory:

   ```powershell
   python -m uvicorn main:app --reload
   ```

2. Set `GROQ_API_KEY` in `backend/.env` before you start the API. The API reads this file when it starts.
3. Install the frontend packages and start the frontend from this directory:

   ```powershell
   npm install
   npm run dev
   ```

4. Open `http://localhost:3000`.

The frontend uses `http://localhost:8000` as its default API address. Set `NEXT_PUBLIC_API_URL` before you start Next.js to use a different address.

Use `backend/main.py` for the extraction and simulation routes. The separate `backend/app/main.py` app has only `/` and `/health` routes.

## Use the interface

1. Select or drop a PDF file. The API accepts files up to 20 MB.
2. Read the extracted manifest. It contains the equation type, description, variables, time span, and point count.
3. Change the variables with the sliders, if necessary.
4. Select **Run Simulation**. The app shows the last 50 points as JSON and shows the full x/y ranges.

`src/lib/api.ts` sends the file to `POST /api/extract`. It sends the manifest to `POST /api/simulate` and reads the returned JSON lines.

The simulation view does not show a 3D model. It shows the points that the API returns.

Do not use the generated simulation code with untrusted input. The backend runs model-generated Python in a subprocess.
